# Sidebar groups

Users organize their Bot and group-chat entries into named sidebar groups. A sidebar group is only a display arrangement: it does not create a group chat, change its members, or change any Bot's permissions, memory, or working folder.

- A chat belongs to at most one sidebar group. The user can move it from its context menu; unassigned entries appear under Ungrouped. The first Main Bot can also be assigned.
- Groups can be created, renamed, deleted, collapsed, pinned, and moved up or down. Deleting a group releases its entries to Ungrouped without deleting them. Pinned groups precede unpinned groups; each tier has its own order. Entries within each group retain the existing pinned/recent ordering.
- With no groups, the sidebar remains a flat list. The compact rail keeps the existing flat list so every entry stays reachable. Collapsed groups show their counts and indicate unread activity or pending approvals.
- Group definitions and membership live in the team preferences, alongside the existing shared sidebar flags. Changes are individual host operations rather than replacing a stale client copy of the list. They use the existing team lock, save and revision flow.
- A drag handle reorders groups within their pinned or unpinned tier; keyboard-accessible up/down controls remain available. It does not change individual Bot pins or change the order of chats within groups.
